# Diffusion

**简介**：

1. 从底层原理上剖析 Diffusion 模型，带领重温学习 DDPM、DDIM、Flow Matching 等开创性的 Diffusion 原理工作；
2. 讲解 Diffusion 模型的常见架构，从 LDM 到 DiT、MMDiT，讲解 Diffusion 模型架构的进化史；
3. 讨论 Diffusion 的前沿课题，包括但不限于 Editting Models、DiffusionOPD、Memory、High-Resolution，以及在具身智能和生物合成领域的应用等。
